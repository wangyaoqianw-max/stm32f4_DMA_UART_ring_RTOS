# GUI Guider 传感器页面设计

日期：2026-10-04
状态：交互、圆角布局及本文已获用户确认（2026-10-04）。
阶段：先完成 GUI Guider 页面设计，再移植至固件。

## 1. 已确认的范围

- 单页英文深色仪表界面，显示温度、湿度、加速度 XYZ、陀螺仪 XYZ。
- 提供 START、STOP、ONCE 三项操作。START/STOP 共用一个随实际状态切换的按钮，ONCE 独立。
- 分辨率保持 240 × 280，RGB565，LVGL 9.4.0。
- 实屏四角为圆角；标题、状态、底部按钮避开边角。
- 使用纯色容器和文字。第一版不加入图片、图表、动画、多页面或中文字体。

### 圆角约束

- 预览使用 48 px 半径作为暂定遮罩，**不是实测的可视区半径**。
- 标题左侧留 24 px，状态标签右侧留 26 px；按钮左右各留 20 px，底部留 14 px。
- 工程参考规格书 `../02_架构设计/P169H200屏幕参考文件/P169H002-CTP NEW 规格书SPEC.md` 第 1.0 节确认分辨率及显示面积；第 6.0 节外形图显示圆角，但未明确标注显示可视区的圆角半径。不能把外形结构的 R5 标注直接当成可视区半径。
- 圆角通过内容避让处理，不改变逻辑分辨率、现有触摸映射或 LCD GRAM 偏移。原生页面无需另加圆角遮罩对象。

## 3. 状态与交互

| 场景 | 状态标签 | 主按钮 | ONCE 按钮 | 反馈 / 数值 |
|---|---|---|---|---|
| 首次启动，未采样 | STOPPED | START 可用 | ONCE 可用 | No sample yet；数值 -- |
| 连续采集 | RUNNING | STOP 可用 | 禁用 | Live sampling；刷新有效读数 |
| 连续采集停止 | STOPPED | START 可用 | ONCE 可用 | Stopped；保留最后有效读数 |
| 单次采样处理中 | STOPPED | 禁用 | SAMPLING，禁用 | Sampling...；保留历史值，无历史则 -- |
| 单次采样完成 | STOPPED | START 可用 | ONCE 可用 | Sample OK / Sample failed |

- 点击并松开才提交一次控制请求；长按不重复提交。
- START/STOP 请求等待结果时暂时禁用两个按钮，状态标签仍显示已确认状态；收到结果后按实际状态恢复按钮。
- 提交失败显示 Request failed；业务忙显示 Busy。失败不得把页面切换成请求的目标状态。
- 单次采样保持现有 STOPPED/RUNNING 两态业务模型，不增加第三个 Control 状态。
- 串口和实体键的操作结果同样同步到页面；页面不以本地按钮文字推断系统状态。
- 温湿度保留一位小数，加速度保留两位，陀螺仪保留一位；运动数值显示正负号。读数失败保留最后有效值，首次无有效值显示 --，并在反馈栏提示 Sample failed。

## 4. GUI Guider 与固件边界

设计冻结时，工作区 `ui_project/ui_project.guiguider` 为 GUI Guider 2.0.1、LVGL 9.4.0、240 × 280、16 位颜色的空白页面。当前已完成原生页面和真实生成，移植进度以执行计划及本轮验证记录为准。

1. 在此项目中完成上述控件及默认 STOPPED 样式，确保 GUI Guider 能正常打开、编辑、生成。
2. 生成代码只负责页面创建和样式；业务绑定由自研 APP UI 文件负责，不把业务代码直接写进生成文件。
3. 后续固件接入复用现有 LVGL 库和显示/触摸端口，只导入实际需要的生成源码、头文件及字体；不复制 simulator、SDL 或第二份 LVGL。
4. Display Task 保持唯一 LVGL 调用者。UI 回调投递 Control 事件，其他任务通过消息传递状态、结果及测量数据，不直接操作控件。
5. 在 BUTTON/UART 基础上增加 UI 来源，以 Control 快照反馈状态及单次忙标记；UART 原有响应格式保持。
6. 页面采用现有部分刷新方式。24 KiB LVGL 池、9600 B 绘制缓冲和现有任务栈先沿用；新页面实际内存、字体 Flash 和栈余量需在移植后重新核算。

## 5. 验收与停止点

- 页面设计阶段：验证原生工程可打开及生成，检查真实字体、布局、最大读数长度、按钮禁用样式和圆角避让。浏览器模拟数据不作为固件功能证据。
- 移植阶段：先完成受改动模块的 Host 测试、真实 Keil 构建和 map 资源核算。
- 自动检查完成后，在需要烧录及人工触摸验收时停下，通知用户操作；不重复执行已关闭的 LVGL 最小端口整套验收。
- 原生页面及业务绑定已实现；板上显示、圆角可见性、真实传感器及控制同步待人工验收。温湿度数值标签按真实字体行高修正为 y=20 / h=29，不改变卡片尺寸。
